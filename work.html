Project 01

Survival School

MCQ-driven learning platform for universities

Built because exam practice was boring and it didn't have to be. Timed exams with server-authoritative scoring — the client never decides its own marks — plus points and badges, QR-verifiable certificates, timetables and real-time chat. Shipping this taught me databases, auth and deployment the hard way, which is the only way I seem to learn them.

Project 02

Signal-Lite

Security-first real-time messaging platform

I wanted to know how real chat systems work, so I built one the careful way: phone/OTP login with rotating refresh tokens, server-side authorization on every resource, WebSocket fan-out over Redis, and private object storage for uploads. One deliberate quirk — no AI anywhere in the product, and CI enforces it.

Project 03

Chandra's World

A 3D walking portfolio

My portfolio, except you walk through it. A Three.js world with a rigged character, day/night cycle, four seasons, weather and wildlife — a fox that follows you, a wolf patrol, a monkey that hops between rocks. Guided journey or free walk, photo mode included. Every push runs a headless browser test that walks the whole world, because a portfolio that 404s is worse than no portfolio.
