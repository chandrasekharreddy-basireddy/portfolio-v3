# Portfolio v3 — the Jitter edition

My multi-page portfolio, rebuilt from scratch in a light, motion-first design
after [Jitter's](https://jitter.video) free template library. Vanilla HTML,
CSS and JavaScript — no frameworks, no build step, no actual templates.

**Live:** https://chandrasekharreddy-basireddy.github.io/portfolio-v3/

## What's inside

- `index.html` — gradient hero with springy word reveals, skills marquee, stat cards, project cards
- `about.html` — parallax photo-mask reveal, quick facts, gradient timeline, skills cloud
- `work.html` — three project features with animated gradient vignettes
- `contact.html` — draw-on animated SVG icons, gradient email link
- `css/style.css` — the whole design system (light + dark themes via CSS variables)
- `js/main.js` — motion engine: preloader ring, theme toggle, reveals, counters, parallax orbs, ripple buttons, magnetic hover, custom cursor, page transitions

## Jitter patterns implemented

The motion design borrows from Jitter's template library — circular loader
preloader, toggle switch, ripple effect, draw-on icons, bouncy word reveals,
gradient background loops, block-sequence reveals and parallax masks —
re-implemented by hand in code.
