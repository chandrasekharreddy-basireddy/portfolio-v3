# Portfolio v3 — the animated one

My multi-page portfolio: dark, motion-first design built with vanilla
HTML, CSS and JavaScript. No frameworks, no build step.

**Live:** https://chandrasekharreddy-basireddy.github.io/portfolio-v3/

## What's inside

- `index.html` — hero with staggered text reveal, skills marquee, stats, project cards
- `about.html` — bio, quick facts, education timeline, skills cloud
- `work.html` — Survival School, Signal-Lite and Chandra's World
- `contact.html` — email + links
- `css/style.css` — the whole design system (custom properties, keyframes)
- `js/main.js` — motion engine: reveals, counters, parallax, magnetic buttons, cursor, page transitions

Everything else I've built lives at
[github.com/chandrasekharreddy-basireddy](https://github.com/chandrasekharreddy-basireddy).
